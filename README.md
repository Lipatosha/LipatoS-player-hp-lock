# LipatoS — Запрет изменения здоровья

Модуль для **Foundry Virtual Tabletop 14** и **D&D 5e 6.0.5**, который запрещает обычным игрокам вручную изменять здоровье своего персонажа.

## Версия

**1.0.0**

## Что блокируется

- ручное изменение **текущих HP** (`system.attributes.hp.value`);
- ручное изменение **временных HP** (`system.attributes.hp.temp`);
- ввод с клавиатуры;
- удаление и замена значения;
- вставка;
- перетаскивание значения;
- изменение числового поля колесом мыши.

## Что продолжает работать

- автоматический урон;
- автоматическое лечение;
- обновления HP системой D&D5e;
- обновления HP другими модулями и эффектами;
- любые изменения HP со стороны ГМ и Assistant GM.

Модуль специально **не использует `readonly` и `disabled`**, поэтому стандартный внешний вид блока здоровья D&D5e не меняется.

## Совместимость

- Foundry VTT: **14**
- D&D5e: **6.0.5**

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте:

`https://github.com/Lipatosha/LipatoS-player-hp-lock/releases/latest/download/module.json`
